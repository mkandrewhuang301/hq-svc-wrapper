# hq-svc-wrapper
A Replicate (Cog) wrapper for [HQ-SVC](https://github.com/ShawnPi233/HQ-SVC) (AAAI 2026) zero-shot singing voice conversion. This repo contains only the wrapper; HQ-SVC's code and weights ([shawnpi/HQ-SVC](https://huggingface.co/shawnpi/HQ-SVC)) are fetched from their own public sources at build time. Personal testing.
